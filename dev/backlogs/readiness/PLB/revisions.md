2. **The new Gate 3 exception would allow a different file on case-sensitive systems.** Plan:145-147 lowercases both the configured path and the write target on every platform. Separately, Plan:247-248 would make self-check reject any `..`, although setup's existing check (generate.mjs:1031) accepts a contained path such as `a/../reports`.
