## Разпределение по издания (по важност)

### 0.2.3 — Security (счупената гаранция) · tag `v0.2.3`
- **PS-001** + сгънати **READY-004** + **UPD-001**.
- PowerShell огледални `PowerShell(...)` ask-правила за целия списък + Gate 4 matcher покрива втория
  tool; cross-repo enforcement (`git -C` към чуждо repo — READY-004); `/pnp:update` докладва
  правилата, които не е добавил (UPD-001).
- Managed artifact → `reconcile-ask-ruleset` миграция. **Най-важно:** единствената обявена гаранция
  („всеки гейт е native диалог"), която е невярна на всеки Windows консуматор сега; push необгейтен.

### 0.2.4 — Correctness на реален консуматор · tag `v0.2.4`
- **SETUP-001** + **GATE-002**.
- SETUP-001: setup открива непразен `<plansDir>/active/` и предупреждава, вместо да чете чужди
  планове тихо (Gate 2 off-plan).
- GATE-002: честен лимит (кликът одобрява извикването, не крайното съдържание при post-commit
  автоматика) + опционален selfcheck `[NOTE]`.
- Тема: реалната среда на консуматора чупи гейт/инсталация.

### 0.2.5 — Review-loop прецизност · tag `v0.2.5`
- **READY-002** (котва — доказано 9/9) + **READY-003** + **READY-001**.
- Пас N+1 носи блокер-листата на пас N; интеграционен инвентар преди първата чернова; verify
  команди литерални в PLAN + adjacency чеклист.
- Предимно doctrine/skills → note-only миграция. Прави всеки бъдещ R2/R3 по-евтин.

### 0.2.6 — Legibility & housekeeping · tag `v0.2.6`
- **README-001** + **ROLES-001** + **DOC-001** + **„един префикс на план"** (#12).
- Публичното repo се обяснява на студен посетител; одитната таблица групирана/етикетирана + skills
  печатат буквалния изход (пипа pin-натия `--show` формат → selfcheck update); отделният докс commit
  записан; ref-as-lookup + selfcheck assertion + именуване на планове (#12 ражда правилото за
  следващите планове).
