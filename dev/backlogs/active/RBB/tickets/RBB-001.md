Implements: D-01, D-02, D-03, D-04, D-05, D-06, D-10. COO: cheap (Opus) - all four no.
Status: open. Branch: `main`. Depends on: the plan landed in `active/RBB/`.

## Outcome

`/pnp:plan` exists and walks REBUILD's stages 1-6 as one skill; the four agent contracts ship in
`templates/briefs/`; a reader of the skill can run a plan from the roadmap entry to the landing
commit without opening `/pnp:review`'s old steps.

## Scope

Worklist (pointers in `RESEARCH.md`; re-verify before acting):

1. `skills/plan/SKILL.md` (new): frontmatter `name: plan`, `description:`, `allowed-tools: Read,
   Grep, Glob, Bash, Agent`; the Step 0 block copied from `skills/review/SKILL.md:31-47` (the
   self-check phrases and the interlock line); then Steps 1-6 per D-01: (1) the roadmap entry in the
   strict format, (2) research agents dispatched with `templates/briefs/research.md` -> the COO
   writes `drafts/<ABBR>/RESEARCH.md`, (3) `DECISIONS.md` with Deferred and Open Questions; an open
   question STOPS the skill until the operator answers, (4) the planner dispatched as
   `subagent_type: "writer"` (no `model`, no `Ticket:` line - Gate 2's one dialog is expected) with
   `templates/briefs/planner.md`; it writes only under `drafts/<ABBR>/` and returns the handoff
   (D-03); the COO reads the files from disk, (5) the gate: `node
   "${CLAUDE_PLUGIN_ROOT}/scripts/engine/plan-gate.js" --stamp <folder>` (refuses on problems), then
   `--check <folder>`; re-stamp after every revision, (6) the pass: the brief per D-05 written to
   `<scratchDir>/review-brief.txt`, the wrapper call in the shape of `skills/review/SKILL.md:611-622`
   with `-Class plan`, background, stdout to `<scratchDir>/readiness-round.txt`; triage per
   finding; the revision by the planner (the same dispatch over the round file); D-06's pass-2
   triggers, the cap and the stall rule; `readiness/<ABBR>/round-N.md`; the operator's approval;
   the landing per D-04 (`Move-Item`, `git add`, one commit).
2. `templates/briefs/research.md`, `planner.md`, `readiness-codex.md`, `writer-dispatch.md` (new):
   each a complete prompt with placeholders `<ABBR>`, `<folder>`, `<goal>` the COO fills; the
   planner brief carries the folder contract (index + `DECISIONS.md` + `tickets/` with the six
   headings, <= 3 tickets, <= 6144 bytes, a Code Map of existing paths, `plan:` on every decision),
   the write boundary (`drafts/<ABBR>/` only) and the handoff shape of D-03; the readiness brief
   carries D-05's contract and output shape, cites `docs/READINESS_CLASSES.md`, and for pass 2 the
   carried `round-1.md` (D-06); the Writer brief is D-10's three lines.
3. `templates/README.md`: one sentence after :42 - `briefs/` is read by the skills at run time by
   path, never rendered, never managed.
4. `skills/README.md`: the `/pnp:plan` row, if the file lists the skills (unknown, `RESEARCH.md`).

Out of scope: `/pnp:review` and every other skill (RBB-002); any code; `docs/*.md` (RBB-002); the
