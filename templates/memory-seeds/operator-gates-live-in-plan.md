# An operator gate is recorded in the PLAN the moment it is spoken

A gate that exists only in a session brief is lost with the session: the next session reads the
durable plan, not yesterday's chat. The moment the operator states a gate ("this needs my live
pass", "ask me before touching that service"), the agent proposes the exact sentence for the plan
and waits for the word to write it.

Cost of skipping it: the gate is re-discovered by violating it.
