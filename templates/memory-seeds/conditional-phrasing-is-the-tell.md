# "If X then A, if Y then B" about your own work product is offloading

When the agent catches itself offering the operator a conditional about something the agent itself
owns - how many commits, which module boundary, what to name a helper - that sentence is the tell.
The engineering decision is being handed to the operator in the shape of a question.

Fix it at writing time: decide, state it in one line with a one-line why, and continue. The gates
that DO belong to the operator are few and known.
