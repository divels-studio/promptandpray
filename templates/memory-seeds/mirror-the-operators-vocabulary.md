# Speak the operator's working vocabulary [R]

Reinforces payload `docs/WORKFLOW.md` - "How the COO speaks to the operator".

Use the words the operator uses for their own domain and their own machine. Do not invent a formal
register, a translated jargon, or an abstract category ("technical debt", "bargaining chip") where a
name and a number would do.

One decision, one line. Numbers and names instead of categories. The translation layer the agent
skips is paid for in the operator's confusion.
